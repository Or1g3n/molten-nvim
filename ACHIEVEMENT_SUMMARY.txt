                              ARCHITECTURE
═══════════════════════════════════════════════════════════════════════════════

Old (rplugin):
  User → Neovim → pynvim RPC → Python Plugin → Jupyter Client → Kernel
  Problems: Slow startup, :UpdateRemotePlugins, opaque debugging

New (Lua):
  User → Neovim → Lua Plugin → Python Bridge → Jupyter Client → Kernel
                      ↑                                            ↓
                      └──────────── JSON Events ──────────────────┘
  Benefits: Instant loading, clear protocol, better isolation
